# Design references

Codex Browser Use implements the following ideas independently. No source files
from the projects below are bundled, and they are not runtime dependencies.

| Project (MIT) | Inspected revision | Ideas adapted | Deliberate differences |
| --- | --- | --- | --- |
| [pi-control-chrome](https://github.com/lyd123qw2008/pi-control-chrome) | `051676db594908c7cd4ef0f07e61f2b1a2a44c26` | Document-scoped stable refs, conservative rebinding, Chrome AX names, condition waits, bounded output | Rebinding requires a unique strong ID/test ID and matching ancestry, only once. Top-document AX only; child frames use DOM semantics. |
| [mcp-chrome](https://github.com/hangwin/mcp-chrome) | `9fca59a6745632cbc9b469c998976ea3bd562ab2` | Owned CDP sessions, file input selection, dialog handling, download status, bounded diagnostics | Always requires an owned tab. File selection is distinct from server receipt. Download IDs are recorded from explicit plugin downloads, never guessed from global activity. |
| [codex-control-chrome-mcp](https://github.com/iola1999/codex-control-chrome-mcp) | `c701215a63fc5ca6bdc208deb27417cb7da3cb44` | Session lifecycle and connection failure classification | Never rerun a mutation after a connection failure. Returns uncertainty for effects that cannot be verified. |

These are design references, not a claim that the other projects were installed
or tested locally. If source is copied into future versions, preserve the relevant
upstream copyright and license notice with that code.

WorkBuddy 0.2.4 was a functional reference for the initial browser workflow and
interface terminology. Its source, branding assets and private protocol are not
bundled. Codex Browser Use is not affiliated with Tencent, WorkBuddy or OpenAI.
The Chrome extension icons are generated by this project's `scripts/prepare.mjs`.
