# Codex Browser Use 0.5.1

修复 iframe 输入可能被父页面重定向，以及任务在悬停或准备滚动后失败却被误判为可以重试的问题。同时禁止向密码框输入普通字符，并拒绝 UNC/设备上传路径。

## 行为变化

- 跨域 iframe 原生鼠标输入绑定独立 Chrome 子目标与扩展隔离世界的文档标识，移除网页消息坐标交换。父页面临时切换点击目标不会接收到发往该独立子目标的输入。
- 同源嵌套 frame 支持坐标转换；跨域 frame 缺少独立输入目标时返回 `FRAME_ROUTING_UNAVAILABLE`，不采用父页面坐标回退。文档改变、目标断开时停止。
- 只有纯读取阶段失败且检查点成功撤销才返回 `STEP_NOT_SENT`。悬停、拖拽移动、准备滚动后的失败以及检查点撤销写入失败都保留未解决状态。

## 兼容与验证

最低版本为 Windows + Chrome 125+ + Node.js 22+；工具数量仍为 42。更新源码和发布包不会自动更新 Chrome 已加载的扩展或 Codex 缓存副本，安装方式见 [README](../../README.md)。

执行 `npm run check`、`npm test`、`npm run test:browser`，暂存后执行 `npm run check:release`。浏览器回归使用一次性 Chromium 配置，覆盖真实子 frame 输入和最终检查之后的父页面目标切换；不触及个人登录配置或 Windows 安装注册表。
