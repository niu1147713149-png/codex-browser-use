# Codex Browser Use 0.5.0

让 Codex 在你已经登录的 Chrome 中操作指定网页，通过页面证据定位目标、核对结果，并在断连后恢复任务检查点。

## 包含内容

- Chrome Manifest V3 扩展、Windows Native Messaging 安装器、MCP 服务和调用 skill，共 42 个工具。
- 已有标签页接管、语义定位、原生点击和键盘、表单填写、iframe、截图、文件输入、显式下载与有限诊断。
- 相同值/URL 跳过、Chrome 配置标识、页面登录证据、持久任务步骤去重与结果核查。
- 实际播放器识别、播放/跳转、带时间的解码帧和音轨采集，可选本地语音转写。

## 安装

解压 `codex-browser-use-0.5.0.zip`，从项目根目录执行 `scripts/install.ps1`，再在 Chrome 开发者模式下加载 `extension/`。详见包内 README。

需要 Windows、Chrome 116+、Node.js 22+ 及支持插件的 Codex CLI。备用 MCP 安装也见 README。浏览器控制运行时无需 npm 依赖或额外 API Key。

## 已知边界

当前安装不支持 macOS/Linux。一次连接一个 Chrome 配置。账号状态来自页面证据；缺证据时不保证具体账号。视频是画面采样和音轨证据，不保证逐帧覆盖、全部评论、DRM 或所有平台可用。任务恢复不自动重放不确定的动作。

发布 ZIP 附 SHA-256 与文件清单。自动化检查范围见仓库 Actions；真实 Chrome 联调需按 CONTRIBUTING 手动执行，个人浏览器报告不随包发布。
